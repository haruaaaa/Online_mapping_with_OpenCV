# Online_mapping_with_OpenCV

Сабмодуль автономного картографирования, предобработки лидарных данных и хранения эталонной карты арены для Хакатона StarLine 2026.

---

## 1. Назначение и состав

### 1. Эталонная карта полигона (`map.yaml`, `my_maze_map.pgm`)
- Содержит точную 2D OccupancyGrid карту соревновательного полигона.
- Используется узлом AMCL (Nav2) для глобальной локализации обоих роботов на старте и во время матча.
- Используется планировщиками `grid_nav` и `obstacle_map` для построения потенциальных полей и фильтрации стен.

### 2. Пакет `exploring`
Содержит узлы предобработки сенсорных данных и исследования:

- **`livox_to_laserscan`**:
  - Конвертирует 3D-облако точек Livox MID-360 (`/livox/lidar`) в 2D лазерный скан (`/scan` и `/scan_body`).
  - Фильтрует срез по высоте (0.15–0.60 м), исключая отражения от пола и потолка.
  - Исключает стойки собственного корпуса робота, предотвращая сбои локализации AMCL.
  - Фильтрует единичные выбросы пыли и бликов (`min_points_per_bin: 2`) и изолированные лучевые артефакты (`filter_outliers: true`).
  - Ретранслирует команды управления `/cmd_vel` (TwistStamped) в аппаратный топик базы Kobuki `/commands/velocity`.
- **`explore_cv`**:
  - Алгоритм фронтирного исследования модульного лабиринта на основе компьютерного зрения OpenCV при запуске со `slam:=true`.
  - Выделяет границы между исследованными свободными областями и неизведанным пространством.
  - Фильтрует недостижимые фронтиры с использованием KDTree и карты препятствий.
  - Публикует промежуточные цели исследования в топик `/goal_pose` и маркеры визуализации в `/exploration/frontiers`.

## 2. Сборка и запуск

### Сборка
```bash
colcon build --symlink-install --packages-select exploring
source install/setup.bash
```

### Запуск узлов
```bash
# Конвертер Livox в LaserScan:
ros2 run exploring livox_to_laserscan

# Фронтирный исследователь (при активном SLAM Toolbox):
ros2 run exploring explore_cv
```
