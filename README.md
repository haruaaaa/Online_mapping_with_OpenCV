# Online_mapping_with_OpenCV

Сабмодуль автономного исследования лабиринта для Хакатона StarLine 2026.

## Пакет `exploring`

Пакет `exploring` реализует алгоритм фронтирного исследования модульного лабиринта:
- Принимает OccupancyGrid карту из топика `/map` (SLAM Toolbox).
- С помощью алгоритмов компьютерного зрения OpenCV находит границы исследованных свободных областей и неизвестного пространства (Frontiers).
- Фильтрует недостижимые и опасные фронтиры с использованием KDTree и карты препятствий.
- Выбирает оптимальную точку исследования и публикует целевую позу в топик `/goal_pose` для стека Nav2.
- Визуализирует найденные фронтиры в RViz2 через маркеры `/exploration/frontiers`.
